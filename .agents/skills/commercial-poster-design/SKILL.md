# 商业产品海报设计

以“卖点—视觉证据”为主线，让产品在短时间内可识别、利益点可感知、文案可阅读。不要把黑金、飞溅、悬浮或某种字体当作商业感的固定答案；构图、材质、光线、动态和文字必须共同证明当前产品的核心价值。

## 开始前

从用户输入和参考素材中整理以下参数。信息足够时直接工作；只有缺失项会改变产品身份、合规边界或主要方向时才提问。自行补足的内容标记为建议或假设。

| 参数 | 作用与默认处理 |
|---|---|
| `product_category` | 食品、饮料、个护、家清、日用包装品或耐用品；从产品推断 |
| `campaign_goal` | 新品发布、品牌认知、卖点教育、促销转化或电商点击；从文案和渠道推断 |
| `audience` | 决定利益点、语气、信息密度和视觉强度；未知时给出合理假设 |
| `channel` | 线下海报、电商主图、信息流、社交媒体或门店物料；影响安全区和远近阅读 |
| `poster_size` | 画幅、比例、分辨率和出血；未指定时按渠道建议，不假定所有海报都是竖版 |
| `brand_tone` | 高端、活力、天然、科技、亲和、专业等；转译为形式规则而非风格标签 |
| `key_benefit` | 只选一个主卖点；其余降为证明或辅助信息 |
| `hero_arrangement` | 单体巨像、组合陈列、对角冲击、分解悬浮、使用场景或包装加成分；按卖点选择 |
| `palette` | 背景、主体支撑、强调/CTA 和中性色的角色与比例；优先兼顾品牌资产与产品分离度 |
| `material_cues` | 需要被看见的材质、触感、温度、状态或工艺证据 |
| `lighting` | 主光、轮廓光、补光、透射/背光及背景分离策略 |
| `motion_mode` | 飞溅、粒子、流线、悬浮分解、气流、速度拖影、压缩回弹或静态张力；默认从卖点推导 |
| `motion_intensity` | 0–5；0 为静态克制，5 为高冲击，强度不得损害识别和文字安全区 |
| `copy_blocks` | 活动钩子、产品/价值说明、证明点、CTA 和必要声明 |
| `output_format` | 文字方案、图像提示词、实际图片或设计文件；默认只交付文字方案 |

不得虚构价格、折扣期限、认证、奖项、配方、原产地、临床效果、环保结论或法律声明。用户未提供的品牌标志和包装文字不要臆造。

## 建立卖点—视觉证据主线

先用一句话完成以下关系：

`目标受众在当前场景中，因为产品的可见证据而相信一个核心卖点，并采取一个行动。`

再建立证据表：

| 层级 | 要回答的问题 |
|---|---|
| 核心卖点 | 观众三秒内应记住什么？ |
| 产品证据 | 产品本身哪种形态、材料、状态或使用结果能证明它？ |
| 构图证据 | 尺度、位置、角度和留白如何把注意力送到产品？ |
| 光影证据 | 哪些高光、阴影、透射、轮廓或色温能说明材质与状态？ |
| 动态证据 | 哪个有因果关系的瞬间能强化卖点？若无必要，是否应保持静态？ |
| 文字证据 | 哪句标题负责吸引，哪句负责讲清，哪些信息只做证明或行动指令？ |

任何元素无法回到核心卖点时，删除、弱化或更换。动态和特效不是默认必需项。

## 构图与产品主体

先选产品英雄结构，再安排文字和证明元素；不要用装饰填满画面后才寻找产品位置。

- **单体巨像**：适合新品、包装识别和单一强卖点；依靠尺度、轮廓和细节建立权威。
- **组合陈列**：适合口味、规格或系列产品；必须指定一个主款，避免每件产品同等抢眼。
- **对角冲击**：适合速度、能量、运动或即时效果；保留稳定的文字锚点。
- **分解悬浮**：适合成分、结构、步骤或多层体验；分解方向应解释关系，不做无意义爆炸。
- **使用场景**：适合人体工学、使用结果和生活方式；产品仍需保持可识别尺度。
- **包装加证据**：包装为身份锚点，成分、质地或效果为第二层；不要让成分素材遮挡标签。

主体通常占据最强视觉面积，但具体比例服从渠道、包装形态和文案量。确保：

- 产品轮廓完整或裁切有意图，标签、开口、按钮等识别部位不被特效遮挡。
- 镜头角度解释产品优势；不要只因“更夸张”而使用违背结构的透视。
- 主体、标题和 CTA 各有安全区，远看先见产品与钩子，近看再读证明。
- 配料、道具、场景和人物只作为尺度、用途或卖点证据，不成为第二主角。
- 为不同渠道考虑裁切、出血、缩略图识别和移动端小屏阅读。

## 材质与光影

先列出产品必须显得“像什么”和“处于什么状态”，再选择光线。所有高光、雾气、液滴和反射都要符合表面粗糙度、透明度、含水量与光源方向。

- **食品**：用湿润高光、烘烤/焦化纹理、断面、蒸汽、碎屑或拉伸表现新鲜、热度、酥脆、浓郁；避免塑料感和不合理融化。
- **饮料**：用液体透射、气泡、冰块折射、杯壁冷凝、液面弯月和冷暖轮廓表现冰爽、浓度或清澈；包装标签仍须可读。
- **个护与美妆**：用受控高光、半透明凝胶、霜体纹理、玻璃折射或细腻雾面表现配方与触感；不要用未经证实的医学意象暗示功效。
- **家清与日用包装品**：用干净边缘、真实塑料/纸张粗糙度、清晰封口泵头和接触阴影建立可信度；水花、泡沫或织物流动只在能解释清洁、柔顺或清新时使用。
- **硬质日用品与小家电**：用连续形面高光、金属各向异性、玻璃反射和结构阴影说明轮廓与工艺；不要给所有材质统一的湿亮表面。
- **纸品与纺织品**：用纤维、压纹、折叠、边缘厚度和柔和回弹光表现柔软、吸收或韧性。

默认建立主光、补光、轮廓/背光和背景分离四种职责，不要求一定使用四盏灯。先保证材质可信和轮廓清楚，再增加氛围色。深色背景、暖色光和高光飞溅只是可选策略，不能跨品类机械复用。

## 动态效果

动态必须有来源、方向、峰值瞬间和落点，并说明它证明的利益点：

- 飞溅和液滴：适合多汁、清爽、清洁或流动性；遵守重力、黏度和容器关系。
- 气泡、雾和蒸汽：分别表达碳酸/轻盈、清新/喷雾、温热；不要混为通用氛围。
- 粒子和碎屑：适合香气、酥脆、粉末或成分；控制密度，不覆盖产品识别区。
- 流线、织物和光带：适合顺滑、柔顺、香氛、速度或能量；流向应引导视线回到主体和 CTA。
- 悬浮分解：适合层次、配方或结构说明；保持部件顺序、尺度和装配逻辑。
- 静态张力：高端、专业或极简产品可依靠不对称留白、倾角和光影梯度，不强行添加爆炸特效。

使用前景、中景和背景建立深度，但主体边缘附近只保留少量高价值动态。高强度效果也必须为标题、标签和法律文字留下安静区域。

## 视觉层级与文字排版

默认采用三级信息，不机械规定每级字数：

1. **活动钩子**：新品、限时、场景情绪或一句记忆点，负责停留。
2. **产品与价值说明**：明确是什么产品、主卖点是什么，负责理解。
3. **证明与行动**：规格、成分、功能点、CTA 和必要声明，负责决策。

排版遵循：

- 产品与一级标题形成两个可控锚点；用对齐、色彩或形状建立联系，不让两者争夺第一焦点。
- 一张海报最多使用一种高表现力字形，其余文字保持清晰；字体气质从品牌和卖点推导，不照搬参考案例。
- 用字号、字重、行距、字距、色块和留白建立层级，不用过多描边、发光或倾斜弥补结构问题。
- 徽章和图标只承载真实且次要的证明；同组图标保持视觉重量、文案长度和间距一致。
- CTA 必须可见但不压过产品；小字仍要满足目标尺寸和渠道的可读性。
- 图像模型不能可靠生成长文时，让画面保留干净文字区和占位标题；准确文案在后期排版，不依赖模型直接绘制。

## 色彩与背景

为颜色分配职责：背景负责分离，主体支撑色负责统一，强调色负责卖点或 CTA，中性色负责信息稳定。先检查产品与背景的明度、色相和边缘对比，再追求气氛。

- 食欲、冰爽、洁净、高端和科技需要不同的色温、饱和度与对比曲线。
- 品牌色与产品本色冲突时，通过背景、局部光或中性色缓冲，不任意改掉包装核心识别色。
- 不把黑金、橙红或高饱和度当作“商业广告”的固定色板。
- 关键信息避免只靠颜色区分，并检查文字对比和移动端缩小后的可读性。

## 输出结构

用户未指定格式时，交付：

1. 设计目标、受众和一句话卖点
2. 卖点—视觉证据表
3. 画幅、渠道、安全区与构图说明
4. 产品视角、尺度、镜头和主体表现
5. 材质、光线、背景和色彩方案
6. 动态效果的来源、路径、强度和利益点
7. 标题、产品说明、证明、CTA 和声明的排版层级
8. 制作执行说明、风险与质量检查
9. 用户要求时附图像生成提示词或文件交付说明

适配用户要求的格式，不机械坚持九段。若需要提示词，把成品类型、比例、主体、构图、材质光影、动态、背景、文字安全区和禁止项写成连贯指令；不要要求模型生成大量准确小字。

## 工具路由

- 用户只要策略、版式、文案层级或提示词：停留在文字阶段，不生成图片。
- 用户明确要求生成或编辑视觉：读取并遵守可用的图片生成/编辑技能；若工具不可用，交付可执行提示词和限制说明。
- 用户提供图片时先实际查看；无法访问图片就请求可访问文件或改用文字描述，不假装看过。
- 用户要求 PSD、PPTX、PDF、DOCX 等文件时，先检查对应文件能力是否可用，并执行该能力要求的渲染与验证流程。
- 不调用用户未授权的付费第三方 API，不安装未知代码，不把密钥或受限素材写入交付物。

## 质量检查

交付前确认：

- 三秒内能识别产品、主卖点和主要行动方向。
- 只有一个主要销售承诺，所有视觉选择都能回到它。
- 产品轮廓、包装身份、尺度和关键结构可信，没有被特效掩盖。
- 材质、光源、阴影、反射和动态遵守同一物理逻辑。
- 动态效果说明利益点而非填充空白；克制方案未被强行“炸裂化”。
- 标题、产品说明、证明、CTA 和声明层级清楚，在目标尺寸下可读。
- 没有虚构品牌资产、成分、认证、价格、功效或法律结论。
- 替换为不同产品、画幅、色板和动态方式后，方法仍然成立。

若参考现有广告，只保留可解释的方法和来源记录，不复刻其专有文案、标志、角色、独特版式或近似成品。
